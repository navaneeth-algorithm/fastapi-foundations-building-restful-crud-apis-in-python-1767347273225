# Task: Define Project Scope and Data Model

## Description
Choose a simple resource (e.g., 'To-Do Task', 'Blog Post'). Define its Pydantic model with fields like 'id', 'title', 'description', 'status' (for tasks) or 'content', 'author' (for blog posts).

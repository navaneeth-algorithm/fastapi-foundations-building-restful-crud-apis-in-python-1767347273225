# FastAPI Foundations: Building RESTful CRUD APIs in Python

This roadmap is designed for beginners to Python APIs and FastAPI, focusing on building foundational knowledge and practical skills to create, retrieve, update, and delete (CRUD) resources via a RESTful API. It covers essential Python concepts, web API principles, and hands-on FastAPI development, culminating in a simple capstone project.

## Requirements
- Understand basic Python syntax and programming constructs.
- Comprehend the fundamental concepts of Web APIs and HTTP.
- Set up a FastAPI project and develop endpoints.
- Implement data models and validation using Pydantic.
- Develop all four CRUD operations (Create, Read, Update, Delete) for resources.
- Test API endpoints using a tool like Postman.

## Tech Stack
- Python 3.9+
- FastAPI
- Uvicorn
- Pydantic
- Postman (or Insomnia)
- Git (optional, but recommended for version control)

## Acceptance Criteria
- The FastAPI application successfully runs locally using Uvicorn.
- A Pydantic model is correctly defined for the main resource (e.g., 'Task' or 'Post').
- A POST endpoint successfully creates a new resource, assigns it a unique ID, and returns the created resource.
- A GET endpoint '/resources/' successfully retrieves a list of all resources.
- A GET endpoint '/resources/{resource_id}' successfully retrieves a single resource by its ID.
- The GET by ID endpoint returns a 404 status code if the resource ID does not exist.
- A PUT endpoint '/resources/{resource_id}' successfully updates an existing resource.
- The PUT endpoint returns a 404 status code if the resource ID does not exist for an update.
- A DELETE endpoint '/resources/{resource_id}' successfully removes a resource.
- The DELETE endpoint returns a 404 status code if the resource ID does not exist for deletion.
- All API endpoints are testable using Postman, and requests/responses conform to expected formats.
- The code is organized, readable, and uses virtual environments for dependency management.
